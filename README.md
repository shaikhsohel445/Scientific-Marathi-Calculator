# Scientific-Marathi-Calculator
A scientific calculator in Marathi that supports basic arithmetic, trigonometric functions, logarithms, and additional features like modulo (%) and delete (⌫) operations. Built using HTML, CSS, and JavaScript. 
# Scientific Marathi Calculator | वैज्ञानिक मराठी गणकयंत्र  

## Description | वर्णन  
### English  
A scientific calculator in Marathi that supports basic arithmetic, trigonometric functions, logarithms, and additional features like modulo (%) and delete (⌫) operations. Built using HTML, CSS, and JavaScript.  

### मराठी  
ही मराठी वैज्ञानिक गणकयंत्र आहे जी मूलभूत अंकगणित, त्रिकोणमितीय फंक्शन्स, लॉगरिदम, तसेच मॉड्युलो (%) आणि डिलीट (⌫) सारख्या विशेष वैशिष्ट्यांसह येते. HTML, CSS आणि JavaScript वापरून विकसित केले आहे.  

---

## Features | वैशिष्ट्ये  
✅ Basic Arithmetic Operations (+, -, ×, ÷)  
✅ Trigonometric Functions (sin, cos, tan)  
✅ Logarithm Function (log)  
✅ Modulo Operation (%)  
✅ Delete Last Digit (⌫)  
✅ Square Root (√)  
✅ Supports π (Pi)  
✅ Responsive Design
